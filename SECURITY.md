# Security policy

## This is not a disclosure venue

Do not report undisclosed vulnerabilities here. This database catalogues issues that are
already public. If you have found a new vulnerability in someone's product, report it to that
vendor. If you need help finding the right contact, CERT/CC coordinates disclosure at
https://www.kb.cert.org/vuls/report/.

Issues and pull requests are public the moment you open them. Anything you write here is
disclosure.

## Reporting a problem with this project

For a flaw in this repository itself — the validator, the build script, or the website — open a
normal issue. There is no sensitive data here and nothing to protect.

## Reporting a wrong entry

Open an issue with the entry id and the source that contradicts it. Incorrect remediation
guidance is the most serious kind of error this project can ship, because someone may act on it.
Those are treated as urgent.
